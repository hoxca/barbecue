# barbecue
Barbecue use the starkeeper Voyager Astronomy API to control that the warmup of my camera is done before switching the power off.

# usage

```
hugh⨕shupo:|● ./bin/barbecue --help
Usage of ./bin/barbecue:
  -addr string
    	voyager tcp server address (default "127.0.0.1:5950")
  -level string
    	set log level of barbecue default warn (default "warn")
```
